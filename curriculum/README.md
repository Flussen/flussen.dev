# Curriculum

Personal CV site built with Astro, React and Tailwind.

## Local development

```sh
pnpm install
pnpm dev
```

## Build

```sh
pnpm build
```

## Deploy (Cloudflare Pages)

Use direct GitHub integration in Cloudflare Pages with:

- Root directory: `curriculum`
- Build command: `pnpm install --frozen-lockfile && pnpm build`
- Build output directory: `dist`
